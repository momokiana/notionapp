## 2026-11-18 验证补记

- 实际安装独立签名的x86_64测试包到API 35隔离模拟器；其Hermes字节码与已交付ARM64包逐字节相同，未覆盖手机包。用全新SQLite和只监听回环地址的relay验证：自有scheme首次配对，UI显示爱弥斯及头像，合成问答，App进程重启后历史仍可加载。模拟relay断线时UI显示“等网络恢复”，恢复后主WebSocket与独立通知WebSocket自动重连，仍是同一设备注册和历史。
- App退到后台后，从隔离relay触发一条有唯一标记的合成提醒；在Android系统通知中查到本App发出的提醒，点开后进入App。该测试不用真实GPT、线上通知、真实Agent或真机。
- [独立授权助手](<../../xiaoaixiaoai/scripts/gpt-login.mjs>)的17项合成测试通过，含stdout断开后的清理和已写入授权不丢失。首次真实流程因SSH断开未写入授权；不能仅由离线复现断定该次断开的原因。第二次将服务端授权等待与SSH分开，实测Windows回调路径后由用户在官方页面完成；新服务账户下的私有授权已核对落地。已关闭临时回调和清除探针运行文件。
- 真实GPT文字探针只有1次，不提供工具、不传用户数据、不连真机或电脑Agent，收到“爱弥斯在线”。之后只给新relay启用已核验的同一文字模型；再次经严格TLS检查公开健康端点，结果为模型开启、语音关闭、无已配对设备。这不是手机聊天验收。
- [真机验收清单](<../xiaoaixiaoai-phone-check.md>)覆盖安装包校验、配对、文字、历史、重连和后台系统通知。准备阶段只用未签发的占位值 GET 邀请页，经严格 TLS 确认路径前缀、App 专用 scheme/包名及关闭上游下载；离线配对回归 7 项通过。
- 用户打开 App 后，已通过私有文件交付一次性首次配对邀请。初次截图中的项目与源码 `mock://demo` 数据对应，不是线上项目；当时新服务健康检查为 0 台注册。合成测试确认扫码、粘贴及手输均保留路径前缀。
