# 架构与安全语义

```text
来源程序 → 事件持久账本 → 可选 ntfy → UnifiedPush / Android
              ↑                           ↓
     原事件更新 / 来源回执 ← 精确核验 ← 用户回应
```

## 模块

- `server/`：Fastify HTTP、SQLite 事件/回应/历史/幂等账本，来源命令与分层回执，可选设备认证与通知消费者。
- `android/`：Compose 收件箱/详情/设置，Keystore 加密连接与持久未决请求，离线只读缓存、通知偏好及 WorkManager 接收任务。
- `pi-host/`：与服务同进程的可选专用 Pi SDK 会话，显式初始化、私有配置、单写者；不是发现或接管现有终端会话。

## 正确性边界

1. 认证、来源代次、版本、期限及授权在实际受理门核验，不依赖按钮禁用或旧预检。
2. 回应、占用、历史、幂等事实在事务中保存；来源与推送分别保留 unknown，不以超时推断未执行。
3. 原 ID / 正文 / 目标保持不变。已知原生收件允许对账回填，不换 ID 或渠道重发来消除未知。
4. 用户暂停/完成不代表撤回在途外部效果；迟到进展不重新打开已结束事项。
5. 事件列表不是更新订阅或跨页一致快照；离线缓存不是当前授权。恢复在线后须刷新权威状态。
6. 推送只携带最小事件引用、版本及回执关联材料，不携带事件正文、来源会话或服务凭据。完整端点也应视为敏感资料。
7. 来源收件、模型完成、来源自报和独立验证分别记录；来源只读查询不是 AI 输入通道。

## 运行与恢复

默认只回环，无默认 token、AI 输入主机、模型调用或公共推送服务。正式使用须自行配置私有目录、凭据、TLS、推送 ACL 和适用平台权限；模型调用可计费，必须显式启用。

本次公开 Pi 宿主包含既有离线加密备份和冻结安装源码，不包含后继 T014 受控启用。冻结不等于已恢复可执行；旧快照中的凭据、预算和未知操作不是当前许可。不能删标记、重置 ID、清库或迁入私人会话来制造成功。

本仓库不发布私人运行配置和原始证据，不为具体云端进程、设备、部署或模型费用授予操作许可。
