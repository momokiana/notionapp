- 此文件的 SHA-256：`78b8c244f682dd48f6264535e18037f68c7a16c0c6aabc393cfd5827b273a6e3`。如需核对，Windows 可在下载目录运行 `Get-FileHash -Algorithm SHA256 -LiteralPath '小爱小爱-0.1.0.apk'`。
- 手机方便再联系管理员发**新的单次邀请**，不要使用测试占位链接。邀请链接、二维码、配对码只供这次配对，不截图、不转发。不要继续使用演示数据页；出现 HTTPS 证书异常时先停，不绕过系统警告。
- 默认由用户在手机上安装和操作。若需代为 USB 安装，先核对目标真机，再单独确认；不卸载旧应用、不清除数据、不读设备凭据。
- “和弦本”“桌面宠物”等是内置演示数据。演示页可直接点「设备 → 扫一扫」扫描本次邀请，不用 USB，也不用先退出演示。若只用同一台手机粘贴链接，可先在「设置」顶部确认是「演示模式」，再点「更换服务器 / 重新配对」回到输入页。若显示其他真实服务器，不先撤销授权。**演示也可能显示在线**；真正配对时要核对设定的服务器（含 `/xiaoaixiaoai` 路径）与独立 relay 的设备计数。未接电脑时 Agents 列表为空是正常的。
- 扫码后若报网络错误，先用同一台手机、同一网络在浏览器访问邀请的服务器基址加 `/v1/health`（不是带配对码的邀请链接）。若返回 `"ok": true`，说明该浏览器经当前网络能到达服务；若超时，可先换 Wi-Fi/移动数据，再考虑用已有可信 VPN，注意 App 不能被分流排除。App 不要求注册 VPN、也不应忽略 HTTPS 证书警告。
