## Magpie：资源管理候选

尚未唯一定位用户所指仓库。待用户提供准确链接后再核固定版本、许可证与实际机制；不把同名项目混用。

可用于查漏的问题：
- skill、MCP网关、工程memory等资源是否有显式目录和来源/版本/类型？是否禁止默认扫描私人目录？
- 发现、可见作用域、配置、依赖、启停、兼容和安全引用分别由谁负责？
- 资源被发现/启用是否错误等同于工具执行授权？停用后原unknown/回执如何保留？

资源目录不等于工具执行器，工程记忆不等于公共运行账本；是否需要这些资源类型和管理范围仍按本产品需求及后续决定。
