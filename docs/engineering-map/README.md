# HTML工程地图的使用与维护

## 打开

主入口是上一级的 `engineering-map.html`。在本地文件管理器直接双击，用现代浏览器打开即可；不启动后端、不填凭据，不需要CDN、联网字体或插件。也可以只复制这个HTML到别处运行；源码/文档链接则需要原仓库目录布局。

GitHub的文件预览不执行HTML里的交互脚本，请先下载文件再打开，不要把源码预览当作工具已启动。

## 查漏补缺

1. 左侧选系统展开二级功能和三级合同。实线表示包含，虚线表示跨系统依赖；节点端口不是可向后台发请求的操作口。
2. 搜索系统、用途、需求编号、HTTP方法/路径或参考候选。选择结果定位节点，右侧展开接口可看输入、输出、调用方/接收方、权限与回执边界。
3. “查漏补缺”按缺合同、实现落点待补、证据待核、需产品决定分开列出有依据的提示。点击提示定位负责功能。零结构缺项只表示这份清单已关联，不证明产品实现完整。
4. “关键路径”串看云端往返、离线/未知恢复、本地观察、主动新对话、媒体、备份恢复或消息入口。提案步骤没有冻结HTTP路径，不能用已有接口补造能力。
5. “聚焦关联”显示选中项的直接上下游和层级上下文；拖动空白平移、滚轮/按钮缩放、适配全图或恢复1:1。缩小全图是主动操作，首次打开保留可读字号。

键盘：`/`或Ctrl/Cmd+K查找；搜索结果用上下键和Enter；画布方向键平移，`+/-`缩放，`0`适配；连线可Tab聚焦后Enter选择；Esc收起查找/抽屉或退出关联聚焦。窄屏通过左上系统抽屉和右侧“详情”按钮阅读。

## 数据与构建

- `data.py`：公开友好的目标功能、源码/合同落点、关系、盘点提示与引用。没有凭据、实例ID、运行扫描或后台读取。
- `template.html`：原生HTML/CSS/JS、节点/连线、离线图形及交互。
- `build.py`：只用Python标准库，校验节点/合同引用并内嵌为单HTML。公开适配只检查本公开树已有文件/片段：缺失材料仍保留原合同引用，但渲染为不可点击的“本地合同”索引，不因缺链导入未审源码或私有TASK/证据。文件存在也不表示具备本地同名文件的全部接口。

```sh
python3 docs/engineering-map/build.py
```

生成结果不依赖这些构建文件或Python才能打开。修改后需重新构建；引用实际契约时核模块README/严格路由，不凭目标需求命名新API。工程执行状态唯一见 `../roadmap.md`，本工具不写入它、不维护完成率/审查状态、不调用产品服务。

[参考候选](REFERENCE-CANDIDATES.md)分别记录Magpie资源管理与Prime Agent消息处理的待核问题；准确仓库/版本/许可证未确认，不是选型。原始私人截图不进入公开增量。
