# 工程地图工具上下文

仅约束 docs/engineering-map.html 及本目录的构建资料，不改变全产品协作规则、权限或开发暂停范围。

## Register

product

## Users

产品拥有者和实现者，在桌面浏览器盘点完整需求、追踪系统间合同并查漏补缺；窄屏仍能查找节点和阅读详情。没有后台登录或在线API请求。

## Product Purpose

以A–J系统、二级功能、三级合同/能力详情及跨系统关系，让用户从“应具备能力”对照“现有落点、尚缺或待核实内容、需求/验收依据”。区分合同、实现落点、证据待核和产品决定，不输出模糊完成率。执行状态唯一链接roadmap。

产品客户端改为H5先行、安卓H5＋原生壳后，本工具仍只做文档查漏；不是产品H5 UI，不给产品指定前端库/壳实现。Compose代码引用属于保留的历史参照，其通过不迁签新端；后端不因UI路线调整重做。

## Brand Personality

清楚、克制、可追溯。不是营销页面。

## Visual Reference

用户给定的全局和节点近景：左分类、上工具、点阵画布、分组节点/端口、实线层级、说明虚线依赖、右详情。参考图片不进入源码/发布，不复制业务名、水印或示例接口。

## Anti-references

普通Markdown排版网页、只有Mermaid源码或截图、假刷新/在线数据、进度治理平台、把目录存在当完整功能完成。

## Design Principles

- 默认可读，通过聚焦/层级展开控制密度，不靠缩小全部文字塞下全图。
- 数据模型驱动节点、关系、接口数量和需求映射；未知和提案有明确依据。
- 单HTML离线可用；不加载CDN、字体、模型或产品服务。
- 交互可被键盘操作；触屏支持平移/缩放，窄屏用抽屉阅读。

## Accessibility & Inclusion

采用清晰文字和图例，不只以颜色区别关系或缺口。可见键盘焦点、可访问控件名称、正文对比、浏览器缩放及减少动态效果；不宣称已完成跨浏览器/真机无障碍验收。
