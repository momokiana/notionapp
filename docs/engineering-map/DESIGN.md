# 工程地图视觉约束

场景：用户在白天桌面屏幕前对照需求查系统缺口，长时间阅读节点和接口，需要参考图的浅色技术画布，而非黑色终端或营销大屏。

- 注册为产品工具，用户给定布局和交互已经明确；不另设视觉审批。
- 纯白面板、浅中性点阵画布、深色正文。克制配色；种子268°只用于选择/焦点，青绿/赭红区分合同语义，系统字母始终保留。
- CSS颜色采用OKLCH；正文1rem、辅助0.875rem、标题1.125/1.25rem。系统中文sans＋可选代码等宽字体，不联网取字体。
- 左系统索引约208px，右详情约350px，画布使用剩余空间；中屏详情抽屉，窄屏索引/详情按需展开。图形节点是实际可操作对象，圆角8–10px，无装饰阴影/侧色条。
- 层级实线；跨系统依赖虚线、端口与文字说明。连线路由避开节点矩形，默认视图保可读缩放，适配全图由用户主动选择。
- 缺口分合同、实现落点、证据待核、产品决定；这是有依据的静态盘点，不是第二份手填完成状态。
- 控件统一形状和焦点；不做开场动画，尊重prefers-reduced-motion。地图单文件运行，无框架、CDN、在线刷新或遥测。
