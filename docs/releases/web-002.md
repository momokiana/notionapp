## 产品范围

- 明确保存已查看问题的按钮/文字草稿，最多8份；本机全局快捷回复最多12条。模板只追加文字，不自动保存或发送；迟到修改按id/revision拒绝。共享128KiB整根预算，不保证最大字段同时装入，超限保原材料。
- 离线重开**仅指事件API不可达，而HTML/JS/CSS仍实际可加载**。输入准确原凭据可重建本机namespace并看草稿，但不代表API已认证；恢复连接不自动POST。
- schema1读取不伪称已迁移。首次明确写草稿/模板才在原Web Lock和同一严格IDB事务迁schema2，保留marker/store_id/pending/outcome；旧001对schema2拒绝降级。坏根或缺marker不重建。
- 联网核对只GET原事件；真正提交仍须显示当前问题/完整原文并再次确认。原锁内重读草稿和事件，同事务将原草稿转为带恢复材料的prepared槽，再持久unknown，最后POST；保存失败不发送，不嵌套同一把锁。
- 确定首次拒绝与结果未知严格区分。未知只核原response_id，不重放/换ID、不清原槽或自动复活第二份草稿。换身份/目标、编辑、失前台、跨tab修订使确认失效。
