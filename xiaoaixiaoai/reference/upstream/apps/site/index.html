工作原理

电脑 → 中转 → 手机，一条线连起来

  1. 01

    每台电脑照常跑 agent

    在 herdr 里该怎么跑还怎么跑。每台电脑执行一次 herdr-pocket up，守护进程读取本机的 agent，把状态快照发布出去。

  2. 02

    你自己的中转服务

    中转服务跑在你自己的服务器上：WebSocket 长连接、传输压缩；设备令牌只存哈希，agent 归属由服务端按连接身份改写，电脑不能冒充别人。

  3. 03

    手机实时看到一切

    手机扫码配对一次，所有电脑上的 agent 就实时出现在列表里。对话和终端走实时流，断线时自动退回轮询补齐。

  4. 04

    再从口袋里指挥回去

    回一句话、按 Esc、开一个新 agent，或者直接交给小羊去办，指令沿原路送回电脑。电脑之间也能用命令行互相调用；只读模式和设备白名单随时可开。

对话

排版好的对话，不是一屏乱码

工具调用收成卡片，失败的标出来，思考过程淡淡带过。想插一句，就像聊天一样回它。

终端

真正的终端，直接敲

实时终端画面，打字直达 agent。App 自带紧凑键盘，Esc、Tab、方向键、回车、Ctrl+C 一按即达，系统输入法不会挡住画面；选菜单、打断都不用回到电脑前。

设备

扫一下，新电脑就加进来

新电脑运行 herdr-pocket up 显示二维码，用已连上的手机扫一下、点“允许加入”。二维码就是一个 https 链接，手机相机也能直接打开；邀请码一次性、10 分钟过期，手机也能邀请别的手机。

小羊助理

小羊替你盯着，说一句就去办

App 的第一个页面就是小羊。说一句，她直接去做：给 agent 发消息、按键、新建空间，或在任意一台电脑上启动装好的 agent 并交给它任务，再把真实结果告诉你。agent 跑完或卡住时，她会主动来说一声。

  • 问一句就知道

    “谁在等我？”“哪个跑完了？”“今天花了多少？”小羊会去每台电脑看一眼再回答，花费能按 agent、空间、电脑分开算。

  • 主动来找你

    agent 跑完或卡住，小羊会发消息；让她盯着某个 agent，跑完就来叫你。App 关着也会推到通知栏，走的是手机上的常驻连接，不依赖 Google 推送。

  • 帮你记着，帮你查

    “半小时后提醒我看部署”，到点就提醒。出了问题就问她“卡在哪一步”，她会去翻中转服务和各端的日志。

  • 说了就做，照实回报

    发消息、按键、新建空间、启动任意装好的 agent（Claude Code、Codex、Gemini、Kimi……），小羊直接去做，再照实告诉你结果，比如“发了，它还没回”“它正在忙，已排在输入框里”。想让她先问你，设置里打开就行，默认关闭。

  • 模型随你选

    Anthropic，或任意 OpenAI 兼容服务：DeepSeek、Qwen、Kimi、GLM、OpenRouter，也可以是本地的 Ollama。

语音通话

给小羊打个电话。

常见问题

你可能想问

支持 iPhone 吗？

目前只有 Android 版 App。电脑端支持 macOS、Linux 和 Windows，能跑 herdr 就行。

能看哪些 agent？

herdr 里跑着的都能看：Claude Code、Codex、Gemini、OpenCode、Kimi、Qwen、Cursor Agent、Droid、CodeBuddy、Qoder、omp、pi 等，普通终端程序也可以，认得出的会显示专属头像。电脑上装好的 agent CLI，小羊也能直接帮你启动。

一定要自己部署服务器吗？

是的，中转服务由你自己部署，数据只经过你的服务器。用 Docker Compose、一键脚本或 Cloudflare Tunnel 都可以。

中转服务能看到我的内容吗？

能。当前版本没有做端到端加密，中转服务能看到明文，所以请部署在你信任的服务器上，并且务必走 HTTPS。设备令牌只存哈希，可以随时吊销。

小羊会直接动手吗？

会，你说了她就去做：发消息、按键、新建空间、启动 agent，做完把真实结果告诉你，比如“发了，它还没回”或“它正在忙，已排在输入框里”。想每次先确认，就在设置里打开“动手前先问我”（默认关闭）；语音通话中她不会停下来等确认。只想让手机看、不让它动，见下一条。

助理和语音用什么模型？

文字助理可以接 Anthropic，或任意 OpenAI 兼容服务（DeepSeek、Qwen、Kimi、GLM、OpenRouter、Ollama 等），在服务器上配置。语音通话默认用 MOSS-Live，更多实时语音服务正在接入。不配置就没有助理或语音，其他功能照常用。

App 关着也能收到提醒吗？

能。提醒靠手机上的常驻服务连着你的中转服务，不经过 Google 推送。部分国产系统需要在设置里允许它在后台运行。

能只让手机看、不让它操作吗？

可以。电脑端用 herdr-pocket run --read-only 只允许查看，或用 --allow 只让指定设备操作这台电脑。

可以改了拿去用吗？

可以，个人和商用都行。Herdr Pocket 以 AGPL-3.0 开源：修改后拿去对外提供服务的，也要公开改动后的源码。

出了问题去哪儿查？

中转服务、电脑和手机的日志都汇总在你的中转服务上。命令行用 herdr-pocket logs 按时间、设备、级别筛选；也可以直接问小羊“卡在哪一步”，或者打开中转服务上的 /admin 网页面板。
