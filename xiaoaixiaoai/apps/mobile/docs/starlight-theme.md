# 星海蓝粉 · 小爱小爱 0.1.2

以用户选定的爱弥斯头像为调色参考：冰蓝取自发饰光边和背景，樱粉衬发色，少量雾紫用于过渡。装饰借鉴[爱弥斯角色档案「长航的星辉」](https://news.17173.com/content/02012026/220155017.shtml)的星海意象，用本地绘制的星芒和双色轨迹，不新增游戏素材、不替换头像。头像另见[素材权利说明](<../assets/brand/USER-ARTWORK.md>)。

| 用途 | 浅色 | 深色 |
|---|---|---|
| 天空至地平线 | `#E5F5FF` → `#FDEAF4` | `#111F33` → `#2C2034` |
| 爱弥斯的回复 | `#EAF7FF` | `#263E54` |
| 用户的消息 | `#FBE3F0` | `#462D46` |
| 主要操作 | `#F3AFD0` | `#F4A8CC` |
| 正文 | `#30344E` | `#F4F4FC` |

[共用色板](<../src/theme/palette.ts>)覆盖页面、弹窗、选中标签、卡片和控件；[星轨装饰](<../src/components/Starlight.tsx>)不拦截触摸，也不进入读屏焦点。现有「跟随系统 / 浅色 / 深色」选项保留。通知、配对、聊天、服务地址和语音接入逻辑不变；语音页只更新配色，不启用服务。

[色板测试](<../test/theme.test.mjs>)检查明暗模式的正文、气泡、按钮配色达到选定的 4.5:1 对比度，输入框轮廓达到 3:1，并核对原生启动色。连同身份回归共 7 项通过，TypeScript 通过，Expo lint 无错误（3 个既有警告）。

[0.1.2 安装包](<../../../dist/小爱小爱-0.1.2-星海蓝粉.apk>)仅更新手机客户端：包名和签名证书与 0.1.0 相同，版本代码为 1002。包含 ARM64 和 x86_64，手机和模拟器可测试同一份签名包。0.1.1 初测发现小屏欢迎头像与顶部状态重叠，0.1.2 缩小头像并把欢迎内容放进可滚动区域。API 35 模拟器用同一 APK 覆盖安装，保留测试配对，[浅色](<../../../dist/星海蓝粉-浅色.png>)与[深色](<../../../dist/星海蓝粉-深色.png>)的头部状态均未被头像遮挡。测试用本地假服务，不是线上或真机复测。

已核签，旧安装包未覆盖，远程更新仍关闭。0.1.2 APK SHA-256：`083e484c10e276aa3aaff9c060821fe4c8dd86d09a4814375ecfeb09aa15f537`。没有操作真机或改动线上服务。
