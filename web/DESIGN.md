# Web 界面约定

## 使用场景与基调
白天桌边或通勤中快速核对一件事，先清楚读正文再确认。使用浅色、高对比、restrained 策略；品牌未命名，语气准确、克制、可追溯。

## 色彩
impeccable palette seed-185，hue170 teal。全用 OKLCH：背景纯白；侧栏低彩度近中性；深墨正文；teal 仅用于当前选择、主要操作和状态。错误/警告独立语义色且总配文字。没有渐变文字、侧边装饰条、玻璃卡片或大阴影。

## 字体与间距
系统无衬线含中文回退。一套字族，正文16px，标签14px，详情标题24px。正文最大72ch。紧凑元信息与宽松正文形成层级；主要控件最小44px。圆角8px，边界以细线与留白区分，不嵌套卡片。

## 布局
顶部产品名/前台连接与设置；桌面约360px列表＋弹性详情。窄于760px收起未选列，详情有返回。设置为独立页面区域而非强制modal。收件箱和历史明确窗口上限、加载更多与过滤范围。

## 状态与交互
标准button/input/select/textarea；可见focus；150ms颜色/背景过渡，不播放进入动画；prefers-reduced-motion关闭过渡。加载骨架与明确阶段文字。未连接、空收件箱、筛选无结果、断网旧页、提交未知、已保存但刷新失败均有具体文案。已读必须明确点击，已保存绝不标为已执行。
